# Third-party materials

This project uses the Python standard library. No third-party runtime package, font,
icon, image or framework code is bundled. The report's SVG/CSS/JavaScript is project code.
Public hardware facts are summarized with links and provenance; source articles, figures,
papers and original reference-report text are not redistributed.

HexaHarness is an external, separately installed development tool. Its implementation and
raw local logs are not part of this repository. Project configuration and sanitized factual
execution receipts describe its use without relicensing the tool. No public source license
is granted by a private repository; all rights not explicitly granted are reserved.
