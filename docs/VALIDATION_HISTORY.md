# 검증과 공개 반영의 날짜별 기록

이 기록은 구현·문서 작성 시점과 후속 검토·게시 시점을 구별한다. 문서에 있는 과거 상태를 소급하여 성공으로 바꾸지 않는다. 모든 시각은 UTC다.

## 2026-10-29 05:45 — 두 심층 사례의 제한된 관리형 수락

당시 PsOs 검토와 센서는 두 사례 보완판을 수락했다. 전체 원요구에 대한 Gate 2/3는 PARTIAL이었다. 이 수락은 이후 전체 19축 판본의 최종 수락을 뜻하지 않는다.

## 2026-10-29 07:10 — 전체 19축 로컬 분석판 검증

실제 HexaHarness 1.0.0 작업의 build·syntax·99개 회귀 검사가 통과했다. 별도 수치 검토 21/21, 의미 검토와 실제 Ego Lite desktop/mobile 조작 및 보존 화면 검토를 수행했다. 전체 19축은 14개 분석·4개 정당한 판단 보류·1개 NAND 범위 제외로 연결된다. 실제 통합과 한계는 [제품전략 검토](PORTFOLIO_REVIEW.md)와 [화면 검토](PORTFOLIO_VISUAL_REVIEW.md)에 기록되어 있다.

이 분석 통과는 실제 고객의 미충족 시장, 보정된 성능·전력·p99, 제품 출시 타당성 또는 무인 운영 준비 완료를 입증하지 않는다. HBM5 등 미확인 사양은 null이며 HBF/NAND는 위치 표시만 유지한다.

## 2026-10-29 — 편집 가능한 문서 추가, 최종 관리형 검토 준비

- [프로젝트 가이드 DOCX](DSA_프로젝트_가이드.docx): SHA-256 `e42d5965e61bd0e50c4d78c307c15872d9d03c1db9959fc956589876ec90cc14`.
- [내부 검증 실행 매뉴얼 DOCX](DSA_내부_검증_실행_매뉴얼.docx): SHA-256 `fa45b6491c23d9a4ed9d62323f065daeba7ecae1aa97b3cbf8a62c09a69315cb`.

두 문서는 기존 원고에서 만든 편집 가능한 스냅샷이다. 문서의 “공개 main e394dcd에는 보완 미반영” 및 검토 전 상태는 작성 당시 기록으로 보존한다. OOXML·관계·속성 검토에서 비공개 실측값, 개인 경로, 인증정보, 매크로·첨부 실행 객체를 발견하지 못했고 외부 링크는 등록된 공개 출처와 일치했다. 이 정적 검사는 최종 내용 수락과 별개다.

최신 전체 19축 소스·화면·원고·DOCX를 대상으로 한 추가 PsOs 최종 검토는 이 기록 작성 시점에 아직 실행 전이다. 후속 결과와 공개 반영 사실은 확인된 이후 날짜별 항목으로 추가한다. 기존 두 사례 수락으로 대체하지 않는다.


## 2026-10-29 08:43 — 전체 19축과 DOCX의 독립 내용 검토 통과

추가 독립 검토는 실제 HexaHarness 적용, 원래 요구와 제품 방향의 연결, 시각적 의사결정 결과의 세 기준을 모두 PASS로 판정했다. 18개 독립 산술 확인도 통과했다. 대상은 두 사례만이 아니라 전체 19축과 두 DOCX였다. 검토자는 소스나 산출물을 수정하지 않았으며 화면 판단에는 보존된 실제 브라우저 조작 기록과 다섯 스크린샷을 사용했다. 해당 검토에서 브라우저를 새로 실행하거나 공개 출처를 온라인으로 재조회한 것은 아니다.

## 2026-10-29 08:55–10:40 — 수락 검사 실패 원인 확인과 1회 재검증

첫 자동 수락은 첫 증거 검사에서 300초를 초과하여 실패했다. 내용 검토 PASS만으로 공개하지 않았다. 파일 내용이 로컬에 없는 macOS dataless 상태와 첫 읽기 지연을 확인했으나 종료된 첫 센서의 정확한 정지 파일은 로그로 확정하지 못했다. 파일 읽기 진단과 최대 4개 병렬 읽기를 추가했고, 모든 파일의 전체 해시·파일 identity·정수 나노초 시각 대조를 유지했다. 파일이나 증거의 시각·플래그를 강제로 바꾸지 않았다.

별도 임시 fixture의 20개 결정적 검사에서 이전/수정 검사기의 digest 일치, 실제 파일 교체·symlink·내용 변조·크기 변화·107ns 시각 불일치 등의 거부를 확인했다. 실제 184개 파일의 전체 digest도 기존 캡처와 일치했다. 이는 검사기 복구 시험이며 시뮬레이터의 99개 회귀 시험과 별개다.

성공한 독립 검토와 첫 실패 이력을 보존한 채 자동 수락만 한 번 재시도했고, 10:40 UTC에 네 등록 검사가 모두 통과했다.

| 검사 | 확인한 결과 |
|---|---|
| 실제 HexaHarness 증거 연결 | 설치된 1.0.0의 완료·설정·가이드·build/lint/test 로그·현재 전체 파일 digest·새 완료 산출물의 내용과 정확한 시각 일치 |
| 시뮬레이터 전체 회귀 | 99개 통과 |
| 수치·의미 계약 | 7개 묶음 통과: 공개 구조 산술, 기존 제품/정밀도 대안, Physical AI 미확인 영역, 추천 연결, 미공개 값과 NAND 범위, HTML/데이터 일치 등 |
| 공개 파일 및 DOCX 검사 | 수락 시점의 82개 공개 파일 통과; 두 DOCX의 승인된 바이트·OOXML 검사 포함 |

최초 수락된 공개 파일 집합의 SHA-256 manifest digest는 `a0767eea7af26fcc445aa93dfce12c6c0bc83c9be064853ca009db0592729d6b`다. 게시용 사본에서 그 집합과 바이트 일치를 먼저 확인한 뒤 이 날짜별 기록만 덧붙였다. 이 추가 기록은 수락 후 작성한 게시 메타데이터이며 앞선 수락에 포함됐다고 주장하지 않는다. 게시 전 최종 사본에 대해 공개 파일 안전 검사와 원본 대비 차이 검사를 별도로 수행한다.

판정의 범위는 여전히 14개 조건부 분석·4개 정당한 판단 보류·1개 NAND 제외다. 실제 고객 수요나 미충족 시장, 제품 실측 성능·전력·p99 또는 상용화 타당성을 확정한 것이 아니다. HexaHarness 구조 검사에는 운영 경고 6개가 남아 있으며 무인 운영 준비 완료를 주장하지 않는다. 내부 자료는 빈 입력 템플릿과 검증 절차로만 제시한다. DOCX의 과거 검토 전 상태와 당시 공개 main 설명은 작성 시점 스냅샷으로 보존한다.
